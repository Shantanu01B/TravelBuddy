🚗 TravelBuddy - Master Interview Guide

MERN Stack (MongoDB, Express, React, Node.js) • Placement Interview Preparation Document

Elevator Pitch (2-Minute Summary):
TravelBuddy is a production-grade commuter ride-sharing and group trip planning platform built for university campuses and corporate tech parks. It eliminates costly Google Maps API billing by utilizing an Ordered Route Stop Matching Algorithm ($O(N)$) to connect commuters along intermediate pickup points safely.

1. Core Project Architecture

  • Frontend: Single Page Application built with React (Vite), Tailwind CSS, and Axios REST client.
  • Backend: Express.js RESTful API with MVC Controllers and JWT Middleware authentication.
  • Database: MongoDB Atlas / Local MongoDB using Mongoose ODM schemas.
  • Media Storage: Cloudinary API with fallback image management.

2. Master Interview Questions & Answers

Q1: How does your Ordered Route Stop Matching algorithm work?
Each ride document contains an array of route stops: routeStops: [{ stopName, pickupPoint, stopOrder }].
The search controller evaluates: 
const pickupIndex = ride.routeStops.findIndex(s => s.stopName.toLowerCase().includes(pickup.toLowerCase()));
const dropIndex = ride.routeStops.findIndex(s => s.stopName.toLowerCase().includes(drop.toLowerCase()));
const isMatch = pickupIndex !== -1 && dropIndex !== -1 && pickupIndex < dropIndex;
This checks in O(N) time that the pickup stop occurs before the drop stop in the driver's journey.
Q2: How is the Trust Score calculated?
The Trust Score (0-100) evaluates commuter reliability using 4 weighted components:
  • 40% Weight: Average Rating (out of 5 stars)
  • 30% Weight: Ride Completion Rate (Completed / Total Rides)
  • 20% Weight: Low Cancellation Rate (1 - Cancelled / Total Rides)
  • 10% Weight: Review Volume (Min 10, Reviews Count × 2)
Q3: How do you handle Authentication and Security?
Passwords are hashed using bcryptjs with 10 salt rounds before saving to MongoDB. Upon successful login, a signed JSON Web Token (JWT) is issued. The React client stores the token in localStorage and attaches it to every request header: Authorization: Bearer <token>. Backend middleware verifies the token using jwt.verify().
Q4: How does the Group Trip Expense Splitter work?
When an expense is logged (e.g., Hotel, Food, Fuel), the total amount is divided equally among trip members: perPersonAmount = amount / splitBetween.length. Category totals are aggregated automatically for transparent group accounting.
